# План реализации: DiaNight (Завершено)

## 1. Завершенные задачи [Completed]
1. **[Completed] Программный синтезатор звуков тревоги (`SoundGenerator.java`):**
   - 3 встроенных алгоритмических звука на базе `AudioTrack` в режиме `MODE_STATIC` (`STREAM_ALARM`):
     - `builtin_pulse` (Импульсный бипер)
     - `builtin_radar` (Радар / Сирена)
     - `builtin_chime` (Мягкий перезвон)
   - Поддержка непрерывного цикла тревоги и мгновенного предпрослушивания в настройках.
2. **[Completed] Насыщенный рубиновый цвет тревоги:**
   - Текст сахара при гипо/гипергликемии: `#FF0038`.
   - Глубокий бархатно-красный пульсирующий фон: от `#000000` до `#4A000A`.
3. **[Completed] Регулировка яркости цвета глюкозы и IoB (Диммер):**
   - Ползунок `SeekBar` в настройках табло (15%–100%, по умолчанию 80%) с интерактивным предпросмотром.
   - Динамическое масштабирование цвета через HSV Value.
4. **[Completed] Удержание Wi-Fi и перезапуск (Watchdog):**
   - Внедрён `WifiLock` (`WIFI_MODE_FULL_HIGH_PERF`) против засыпания радиомодуля.
   - Опция «Автоперезапуск Wi-Fi при сбое связи» в настройках.
5. **[Completed] Устранение ошибки 403 при проверке обновлений:**
   - Двухуровневая проверка: GitHub REST API + fallback на веб-редирект `github.com/releases/latest` через чтение `Location` заголовка.
6. **[Completed] Скрытие клавиатуры:**
   - Настроен `windowSoftInputMode="stateHidden|adjustResize"` и убран авто-фокус в `activity_settings.xml`.
7. **[Completed] Версионирование, публикация и установка:**
   - Релиз v1.1.77 опубликован на GitHub и установлен на смартфон через ADB.
