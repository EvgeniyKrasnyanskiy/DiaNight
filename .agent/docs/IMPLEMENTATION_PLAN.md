# План реализации нового функционала: Вспышка при тревоге и Автозакрытие приложения

Этот документ описывает технический план добавления двух новых функций перед релизной сборкой v1.1.58.

## 1. Функционал вспышки камеры при тревоге (Flashlight Notification)
- **Настройка в меню:** Чекбокс «Мигать вспышкой при тревоге» в разделе «Звук тревоги» настройки приложения (`alarm_use_flash`).
- **Логика работы:**
  - При срабатывании тревоги (`startAlarmSound`), если опция включена, запускается импульсное мигание вспышки смартфона (интервал ~500 мс).
  - При отключении/снузе тревоги (`stopAlarmSound`) вспышка отключается, ресурсы камеры освобождаются.
  - Поддержка API 19 (Android 4.4 KitKat via `android.hardware.Camera`) и API 23+ via `CameraManager`.
  - Безопасная обработка исключений (при отсутствии вспышки или отказе в правах приложение не падает).

## 2. Функционал автоматического закрытия приложения в заданное время (Scheduled Auto-Close)
- **Настройка в меню:** Отдельная карточка «Автозакрытие приложения» с чекбоксом «Включить автозакрытие» (`enable_autoclose`) и полем ввода времени `ЧЧ:ММ` (`autoclose_time`, по умолчанию `07:00`).
- **Логика работы:**
  - В `timeRunnable` каждую минуту проверяется соответствие текущего времени значению `autoclose_time`.
  - В момент наступления заданного времени выводится короткое уведомление `Toast` («Приложение закрыто по расписанию») и вызывается `finishAndRemoveTask()` (или `finish()` на API 19), чисто завершающее работу приложения.

## Изменяемые файлы

### 1. `app/src/main/AndroidManifest.xml`
- Добавление разрешения `android.permission.CAMERA` и опциональной декларации фичи `android.hardware.camera.flash`.

### 2. `app/src/main/res/values/strings.xml` & `app/src/main/res/values-ru/strings.xml`
- Добавление локализованных строк для чекбоксов, названий карточек и сообщений об ошибках/уведомлениях.

### 3. `app/src/main/res/layout/activity_settings.xml`
- Добавление чекбокса вспышки в карточку тревоги.
- Добавление новой карточки настроек для автозакрытия с чекбоксом и полем `TextInputEditText`.

### 4. `app/src/main/java/com/diaclock/nightstand/SettingsActivity.java`
- Связывание элементов UI, сохранение/загрузка новых параметров в `SharedPreferences`, валидация формата времени `ЧЧ:ММ`.

### 5. `app/src/main/java/com/diaclock/nightstand/MainActivity.java`
- Реализация импульсного управления вспышкой с обратной совместимостью API 19-33.
- Проверка времени автозакрытия в секундном/минутном таймере часов и аккуратное завершение `finish()`.
