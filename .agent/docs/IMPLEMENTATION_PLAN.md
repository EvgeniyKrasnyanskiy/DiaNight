# План реализации: Программные звуки тревоги, диммер цвета глюкозы и релиз

## 1. Задачи
1. **Программный синтезатор звуков тревоги (`SoundGenerator.java`):**
   - 3 встроенных алгоритмических звука на базе `AudioTrack` (`STREAM_ALARM`):
     - `builtin_pulse` (Импульсный бипер)
     - `builtin_radar` (Радар / Сирена)
     - `builtin_chime` (Мягкий перезвон)
   - Поддержка непрерывного цикла тревоги и одиночного предпрослушивания в настройках.
2. **Насыщенный красный цвет тревоги:**
   - Цвет текста сахара при гипо/гипергликемии: `#FF0038`.
   - Цвет пульсирующего фона тревоги: от `#000000` до глубокого рубинового `#4A000A`.
3. **Регулировка яркости цвета глюкозы и IoB (Диммер):**
   - Слайдер `SeekBar` в настройках табло (диапазон 15%–100%, по умолчанию 80%).
   - Динамическое масштабирование яркости цвета (через HSV Value) для `tvGlucose` и `tvIoB`.
4. **Сборка релиза и версионирование:**
   - Повышение версии в `version.properties`.
   - Сборка `./gradlew assembleRelease` / `./gradlew assembleDebug`.
   - Фиксация изменений в git и push в remote.
