### 🚀 Что нового в релизе v1.1.65:

1. **Официальный ключ цифровой подписи (Release Keystore):**
   - Сборка подписана официальным релизным ключом `dianight.jks`. Теперь обновление поверх ранее установленных версий на устройствах пользователей проходит в один клик.

2. **Исправление визуализации кнопок палитры ночника (Android 4.4 KitKat):**
   - Для всех 10 кнопок палитры внедрена динамическая заливка через `ViewCompat.setBackgroundTintList()`. Каждая пиктограмма показывает реальный цвет без искажения системным акцентом.

3. **Фоновый автопоиск IP-адреса Мастера (xDrip+ Web Service):**
   - Автоматическое бессбойное сканирование подсети по 28 параллельным потокам при потере связи с мастером (более 3 неудачных попыток).
   - Мгновенное восстановление потока данных гликемии при смене IP роутером.

4. **Светодиодная вспышка при тревогах (Flashlight Alarm Notification):**
   - Новая опция в меню настройки тревог: «Мигать вспышкой при тревоге».
   - Импульсное мигание вспышки каждые 500 мс во время активной тревоги.
   - Поддержка Android 4.4 KitKat и Android 6.0+.

5. **Автоматическое закрытие приложения по расписанию (Scheduled Auto-Close):**
   - Новая настройка автозакрытия приложения в заданное время `ЧЧ:ММ` (например, утром в `07:00`).

6. **Обновлённые целевые диапазоны сахара по умолчанию:**
   - Дневной диапазон: **4.5 – 8.5** ммоль/л.
   - Ночной диапазон: **3.8 – 10.0** ммоль/л.

7. **Совместимость SSL/TLS 1.2 для проверки обновлений:**
   - Внедрена поддержка актуальных корневых сертификатов GitHub API на Android 4.4 KitKat.
