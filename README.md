# DiaClock: Glucose & Clock Nightstand 🕰️🩸

DiaClock — это специализированное Android-приложение (Java, API 23+), разработанное для использования в качестве прикроватного ночника в ландшафтном режиме. Оно объединяет в себе стильные часы и мониторинг уровня глюкозы в крови в реальном времени.

---

## Ключевые возможности

1. **Минималистичный прикроватный интерфейс (Landscape)**:
   - Полностью черный фон (`#000000`) для экономии заряда батареи (на AMOLED) и комфортного сна.
   - Использование атрибута `android:keepScreenOn="true"` гарантирует, что экран не погаснет во время использования.
   - Полноэкранный иммерсивный режим (`Fullscreen`), скрывающий системные панели Android.

2. **Динамическое переключение данных**:
   - Автоматическое циклическое переключение по таймеру (по умолчанию каждые 5 секунд, настраивается в секундах) между **Текущим временем (HH:mm)** и **Уровнем глюкозы (mmol/L)**.
   - Плавное затухание/мигание двоеточия (`:`) в часах (анимация "дыхания" альфы от 0.3 до 1.0 каждую секунду), реализованное полностью на базе `Handler`.

3. **Эстетичные цветовые градиенты**:
   - 5 предустановленных современных цветовых градиентов для текста:
     - **Sunset** (Красный -> Розовый)
     - **Sea** (Голубой -> Темно-синий)
     - **Forest** (Зеленый -> Салатовый)
     - **Royal** (Фиолетовый -> Розовый)
     - **Fire** (Красный -> Желтый)
   - Быстрая смена градиента в один клик: просто тапните по центральному тексту!
   - Выбранный градиент мгновенно сохраняется в `SharedPreferences` и восстанавливается при перезапуске.

4. **Интеграция с Nightscout и xDrip+ API**:
   - Фоновый опрос локального сервера по протоколу HTTP каждые 60 секунд: `http://[IP_ADDRESS]:17580/sgv.json`.
   - Полная поддержка безопасной авторизации по ключу **API Secret** (передается в HTTP-заголовке `api-secret`).
   - Поддержка гибкого парсинга JSON: корректно обрабатываются как массивы объектов Nightscout `[{"sgv": 108}]`, так и одиночные объекты `{"sgv": 108}`.
   - Значения переводятся из системных единиц `mg/dL` в международные `mmol/L` (делением на 18.0) с выводом одного знака после запятой.
   - Умная обработка ошибок: при потере связи в статус-баре загорается аккуратная иконка предупреждения ⚠️, при этом на экране сохраняется последнее известное значение (или выводится `---`).

5. **Продвинутые интеллектуальные будильники**:
   - Гибкое разграничение суток на два интервала: **День** (например, `08:00 - 22:00`) и **Ночь** (`22:00 - 08:00`). Границы временных зон настраиваются.
   - Возможность задать уникальные пороги `High` (высокий) и `Low` (низкий) сахар для каждого времени суток.
   - Полноценная интеграция с колокольчиком тревоги:
     - **Желтый колокольчик** (Alarm Enabled) — при выходе уровня глюкозы за текущие пороги воспроизводится циклический системный сигнал тревоги.
     - **Серый перечеркнутый колокольчик** (Alarm Disabled) — будильник выключен, ночник работает бесшумно.
   - Звук автоматически отключается, как только уровень сахара приходит в норму или пользователь отключает колокольчик.

## Требования для сборки

- **IDE**: Android Studio Chipmunk+ (или любая современная версия).
- **JDK**: Java 8 (1.8) или выше.
- **Android SDK**: Compile SDK 33, Min SDK 23 (Android 6.0).
- **Gradle**: 7.4+
