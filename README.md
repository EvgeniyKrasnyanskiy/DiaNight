# DiaClock: Ночник Глюкозы и Часов 🕰️🩸

DiaClock — это специализированное Android-приложение (Java, API 23+), разработанное для использования в качестве прикроватных часов-ночника в ландшафтном режиме. Оно объединяет в себе огромные, легко читаемые часы и мониторинг уровня глюкозы в крови в реальном времени с поддержкой авторизации в xDrip+.

---

## Ключевые возможности

1. **Минималистичный прикроватный интерфейс (Landscape)**:
   - Полностью черный фон (`#000000`) для экономии заряда батареи (на AMOLED) и комфортного сна.
   - Использование атрибута `android:keepScreenOn="true"` гарантирует, что экран не погаснет во время работы.
   - Полноэкранный иммерсивный режим (`Fullscreen`), скрывающий системные панели Android.

2. **Огромные жирные шрифты (Bold 180sp)**:
   - Шрифт увеличен до максимально возможного значения **`180sp`** (для времени и сахара).
   - Интегрирована технология **Autosizing TextView** от Google, которая плавно сжимает шрифт при двузначном сахаре, чтобы вся строка идеально умещалась на любом экране.
   - Применено сплошное жирное начертание (`textStyle="bold"`) без тонких линий для идеального считывания в темноте.

3. **Интерактивный индикатор тренда сахара**:
   - Приложение автоматически парсит направление (`direction`) из xDrip+ и приписывает к числу сахара понятную Unicode-стрелку тренда:
     - `DoubleUp` -> `⇈` (Стремительный рост)
     - `SingleUp` -> `↑` (Умеренный рост)
     - `FortyFiveUp` -> `↗` (Медленный рост)
     - `Flat` -> `→` (Стабильно)
     - `FortyFiveDown` -> `↘` (Медленное падение)
     - `SingleDown` -> `↓` (Умеренное падение)
     - `DoubleDown` -> `⇊` (Стремительное падение)

4. **Динамическая медицинская цветовая раскраска сахара**:
   - Цвет часов (`HH:mm`) остается статичным и красится в оттенок, выбранный в настройках (например, Белый или Синий).
   - Цвет сахара и стрелки тренда меняется **динамически в зависимости от уровня глюкозы**:
     - **Красный**: менее `3.9` ммоль/л (Гипогликемия).
     - **Зеленый**: от `3.9` до `7.8` ммоль/л (Целевой диапазон / Норма).
     - **Желтый**: от `7.8` до `13.9` ммоль/л (Повышенный сахар).
     - **Красный**: свыше `13.9` ммоль/л (Высокая гипергликемия).

5. **Система откладывания тревоги (Snooze) по тапу на экран**:
   - При выходе сахара за рамки нормы звучит зацикленная сирена тревоги.
   - Вам достаточно **тапнуть по любому свободному месту экрана**, чтобы мгновенно заглушить звук.
   - Сигнал отложится на X минут (настраивается в настройках, по умолчанию `60` минут).
   - **Медицинская безопасность**: Если во время откладывания сахар вернулся в норму, то период блокировки сирены **автоматически сбрасывается**. При повторном выходе из нормы сирена сработает мгновенно без ожидания окончания часа!

6. **Настраиваемый цвет текста и мелодия**:
   - 5 Предустановленных цветов для часов + встроенный RGB Color Picker (ползунки Красного, Зеленого и Синего) с превью.
   - Выбор любой системной мелодии тревоги (через встроенный Android Ringtone Picker) и кнопка мгновенного тестирования громкости.

7. **Локализация**: Полный перевод интерфейса, подсказок колокольчика и валидационных ошибок настроек на **русский язык**.
