# DiaNight: Ночник Глюкозы и Часов 🕰️🩸

**DiaNight** — это специализированное Android-приложение (Java, API 23+), разработанное для использования в качестве прикроватных смарт-часов-ночника в ландшафтном режиме. Оно объединяет в себе огромные, легко читаемые часы, мониторинг уровня глюкозы в крови в реальном времени с поддержкой xDrip+/Nightscout, отображение IoB, контроль заряда батареи и интеллектуальную систему безопасности.

---

## Ключевые возможности

1. **Минималистичный прикроватный интерфейс (Landscape)**:
   - Полностью черный фон (`#000000`) для экономии заряда батареи (на AMOLED) и комфортного сна.
   - Использование атрибута `android:keepScreenOn="true"` гарантирует, что экран не погаснет во время работы.
   - Полноэкранный иммерсивный режим (`Fullscreen`), скрывающий системные панели Android.
   - **Умное автоскрытие:** Все иконки настроек, сетевой ошибки и батареи плавно затухают (fade out) через 15 секунд бездействия. Касание экрана мгновенно пробуждает их. Колокольчик тревог скрывается при бездействии только тогда, когда оповещения выключены.

2. **Огромные жирные шрифты (Bold 180sp)**:
   - Шрифт увеличен до максимально возможного значения **`180sp`** (для времени и сахара).
   - Интегрирована технология **ConstraintLayout верстки**, поднимающая основные часы и сахар на 15% выше центра экрана для оптимального считывания в темноте.
   - Применено сплошное жирное начертание (`textStyle="bold"`).

3. **Отображение IoB (Активный инсулин)**:
   - Справа вверху от значения сахара выводится уменьшенное в 3 раза зеленое значение **IoB** (Insulin on Board) в формате `X.XX U` (например, `1.25 U`), помогающее ночью моментально оценить количество активного инсулина в организме. Если поле пустое, оно автоматически скрывается.

4. **Защита от выгорания OLED-экранов (Pixel Shifting)**:
   - Каждые 2 минуты центральная область часов и сахара незаметно смещается по осям X и Y в случайном диапазоне от -16 до +16 пикселей, предотвращая статическое выгорание пикселей дисплея.

5. **Локальный мониторинг и частое обновление**:
   - Интервал опроса локального xDrip+ снижен до **10 секунд**, что гарантирует мгновенное появление новых сахаров без нагрузки на сеть.

6. **Интегрированный индикатор батареи**:
   - В правом нижнем углу отображается иконка батареи (меняется на зеленую с молнией при зарядке) и процент заряда для постоянного контроля питания. Скрывается вместе с иконками при бездействии.

7. **Двухуровневая система откладывания тревоги (Snooze)**:
   - **Автоматический Snooze:** Если тревога играет более 15 минут, а пользователь не коснулся экрана, приложение автоматически отложит будильник на заданный интервал (по умолчанию 60 минут / 1 час) и выведет тост «Сигнал автоматически отложен».
   - **Ручной Snooze:** Достаточно просто тапнуть по экрану в любом месте для заглушения и откладывания сирены на X минут.
   - **Железная безопасность:** Если колокольчик выключен, сирена блокируется абсолютно при любых условиях. При возврате сахара в норму активный snooze автоматически сбрасывается.

8. **Функции для слабоподготовленных пользователей и диагностика**:
   - **Гибридный автопоиск IP (TCP Socket Scanner):** Двухэтапная система автообнаружения. На первом этапе приложение молниеносно пингует порт `17580` во всей подсети с помощью легких сокетов в пуле из 28 потоков. На втором этапе найденный кандидат точечно проверяется по HTTP. Это на 100% устраняет перегрузку Wi-Fi и находит мастера за 4–8 секунд.
   - **Быстрая проверка связи:** Кнопка «Проверить связь» мгновенно пингует xDrip+ с указанным IP и API Secret, выводя точный код ответа (200 OK, 401 Unauthorized или сетевая ошибка).
   - **Справка:** Подробная пошаговая инструкция на русском языке по клику на иконку знака вопроса в настройках.

9. **Премиальная цветовая палитра (15 вариантов)**:
   - Внедрена изящная **горизонтальная прокручиваемая лента из 15 премиальных цветов** ночника (включая Янтарный, Красный для ночного зрения, Пурпурный, Розовый неоновый, Мятный, Лавандовый, Коралловый и Лаймовый).
   - Унифицированный интерфейс: кнопка «Свой цвет» прижата к правому краю, а индикатор текущего превью находится слева от неё, гармонируя с остальными элементами формы.
