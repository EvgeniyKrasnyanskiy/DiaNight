# DiaClock: Ночник Глюкозы и Часов 🕰️🩸

DiaClock — это специализированное Android-приложение (Java, API 23+), разработанное для использования в качестве прикроватных часов-ночника в ландшафтном режиме. Оно объединяет в себе огромные, легко читаемые часы и мониторинг уровня глюкозы в крови в реальном времени с поддержкой авторизации в xDrip+.

---

## Ключевые возможности

1. **Минималистичный прикроватный интерфейс (Landscape)**:
   - Полностью черный фон (`#000000`) для экономии заряда батареи (на AMOLED) и комфортного сна.
   - Использование атрибута `android:keepScreenOn="true"` гарантирует, что экран не погаснет во время работы.
   - Полноэкранный иммерсивный режим (`Fullscreen`), скрывающий системные панели Android.

2. **Огромные жирные шрифты (Bold 180sp)**:
   - Шрифт увеличен до максимально возможного значения **`180sp`** (для времени и сахара).
   - Применено сплошное жирное начертание (`textStyle="bold"`) без тонких линий для идеального считывания в темноте с расстояния нескольких метров.

3. **Интерактивный индикатор тренда сахара**:
   - Приложение автоматически парсит поле направления (`direction`) из xDrip+ и приписывает к числу сахара понятную Unicode-стрелку тренда:
     - `DoubleUp` -> `⇈` (Стремительный рост)
     - `SingleUp` -> `↑` (Умеренный рост)
     - `FortyFiveUp` -> `↗` (Медленный рост)
     - `Flat` -> `→` (Стабильно)
     - `FortyFiveDown` -> `↘` (Медленное падение)
     - `SingleDown` -> `↓` (Умеренное падение)
     - `DoubleDown` -> `⇊` (Стремительное падение)

4. **Полностью настраиваемый цвет текста**:
   - Выбор цвета полностью вынесен в настройки (нажатие на цифры на главном экране отключено, чтобы избежать случайных нажатий ночью).
   - **5 Предустановленных цветов**:
     - Белый (`#FFFFFF`)
     - Серый (`#8E8E93`)
     - Темно-серый (`#3A3A3C`)
     - Зеленый (`#34C759`)
     - Синий (`#007AFF`)
   - **Встроенный Color Picker (Свой цвет)**: Удобное диалоговое окно с тремя ползунками (Красный, Зеленый, Синий) для подбора абсолютно любого оттенка с реал-тайм превью. Выбранный цвет применяется ко всем элементам ночника и сохраняется в `SharedPreferences`.

5. **Локализация и удобство**:
   - Полный перевод интерфейса и валидационных ошибок на **русский язык**.
   - При нажатии на иконку колокольчика (включение/выключение звукового будильника) выводится приятная Toast-подсказка: *"Звуковой сигнал включен 🔔"* или *"Звуковой сигнал выключен 🔕"*.

6. **Интеграция с xDrip+ API**:
   - Фоновый опрос локального сервера по протоколу HTTP каждые 60 секунд: `http://[IP_ADDRESS]:17580/sgv.json`.
   - Полная поддержка безопасной авторизации по ключу **API Secret** (приложение автоматически на лету вычисляет SHA-1 хэш от введенного ключа безопасности и прикрепляет его в HTTP-заголовок `api-secret`).
   - Умная обработка ошибок: при потере связи в статус-баре загорается аккуратная иконка предупреждения ⚠️, при этом на экране сохраняется последнее известное значение (или выводится `---`).

7. **Продвинутые интеллектуальные будильники**:
   - Гибкое разграничение суток на два настраиваемых интервала: **День** (например, `08:00 - 22:00`) и **Ночь** (`22:00 - 08:00`).
   - Уникальные пороги `High` (высокий) и `Low` (низкий) сахар для каждого времени суток.
   - Звук тревоги автоматически прекращается, когда сахар приходит в норму или колокольчик отключается.
