# DiaNight: Ночник Глюкозы и Часов 🕰️🩸

**DiaNight** — это специализированное Android-приложение (Java, API 23+), разработанное для использования в качестве прикроватных смарт-часов-ночника в ландшафтном режиме. Оно позволяет дать новую полезную жизнь старым Android-устройствам (начиная с версии 6.0 / API 23) с обычными экранами (включая не-LED / не-OLED LCD-матрицы), превращая их в круглосуточные мониторы. Приложение объединяет в себе огромные, легко читаемые часы, мониторинг уровня глюкозы в крови в реальном времени с поддержкой xDrip+/Nightscout, отображение IoB, контроль заряда батареи и интеллектуальную систему безопасности.

---

## Ключевые возможности

1. **Минималистичный прикроватный интерфейс (Landscape)**:
   - Полностью черный фон (`#000000`) для экономии заряда батареи (на AMOLED) и комфортного сна.
   - Использование атрибута `android:keepScreenOn="true"` гарантирует, что экран не погаснет во время работы.
   - Полноэкранный иммерсивный режим (`Fullscreen`), скрывающий системные панели Android.
   - **Умное автоскрытие:** Все иконки настроек, сетевой ошибки и батареи плавно затухают (fade out) через 15 секунд бездействия. Касание экрана мгновенно пробуждает их. Колокольчик тревог скрывается при бездействии только тогда, когда оповещения выключены.

2. **Огромные жирные шрифты (Bold 180sp)**:
   - Шрифт увеличен до максимально возможного значения **`180sp`** (для времени и сахара).
   - Интегрирована технология **ConstraintLayout верстки**, поднимающая основные часы и сахар на 22% выше центра экрана (`app:layout_constraintVertical_bias="0.28"`). Это гарантирует оптимальное считывание в темноте и 100% страхует от загораживания текста нижним бортиком настольной подставки под телефон.
   - Применено сплошное жирное начертание (`textStyle="bold"`).

3. **Отображение IoB (Активный инсулин)**:
   - Справа вверху от значения сахара выводится уменьшенное в 3 раза зеленое значение **IoB** (Insulin on Board) в формате `X.XX U` (например, `1.25 U`), помогающее ночью моментально оценить количество активного инсулина в организме. Если поле пустое, оно автоматически скрывается.

4. **Умное адаптивное масштабирование шрифтов (DPI & Content Text Scaling)**:
   - Внедрен интеллектуальный алгоритм автоподбора размеров текста часов, сахара и IoB на основе физической ширины экрана в dp (`widthDp = widthPixels / density`) и **фактической контентной длины строк**.
   - Относительно эталона `800dp` рассчитывается базовый коэффициент масштабирования `scale` (от `0.55` до `1.25`).
   - На узких экранах (`widthDp < 700`, таких как Alcatel Shine Lite) при длинных сахарах (5+ символов) или отображении IoB размер шрифта глюкозы и IoB дополнительно снижается на **10%**, что со 100% гарантией предотвращает обрезание длинных трёхзначных сахаров с двойными стрелками и IoB (например, `14.5⇈` и `0.93`), оставляя символы при этом максимально крупными.

5. **Защита от выгорания OLED-экранов (Pixel Shifting)**:
   - Каждые 2 минуты центральная область часов и сахара, а также вся верхняя статус-панель (шестеренка, батарея, колокольчик, крестик выхода) смещаются в случайном диапазоне от -16 до +16 пикселей, предотвращая статическое выгорание пикселей дисплея на всех статических значках.
   - Двоеточие разделителя часов плавно пульсирует ("дышит") с комфортным замедленным периодом в **2 секунды** для минимизации отвлечения внимания.

6. **Локальный обмен данными без сети (Broadcast)**:
   - Добавлена поддержка встроенного обмена интентами Android (Broadcast) между xDrip+ и DiaNight на одном телефоне. В этом режиме приложение работает полностью автономно без использования сети Wi-Fi/мобильного интернета и без настройки IP-адресов.

7. **Интегрированный индикатор батареи**:
   - В верхнем статус-баре отображается иконка батареи (меняется на зеленую с молнией при зарядке) и процент заряда для постоянного контроля питания. Скрывается вместе с иконками при бездействии.

8. **Двухуровневая система откладывания тревоги (Snooze)**:
   - **Автоматический Snooze:** Если тревога играет более 15 минут, а пользователь не коснулся экрана, приложение автоматически отложит будильник на заданный интервал (по умолчанию 60 минут / 1 час) и выведет тост «Сигнал автоматически отложен».
   - **Ручной Snooze:** Достаточно просто тапнуть по экрану в любом месте для заглушения и откладывания сирены на X минут.
   - **Железная безопасность:** Если колокольчик выключен, сирена блокируется абсолютно при любых условиях. При возврате сахара в норму активный snooze автоматически сбрасывается.

9. **Функции для слабоподготовленных пользователей и диагностика**:
   - **Гибридный автопоиск IP (TCP Socket Scanner):** Двухэтапная система автообнаружения. На первом этапе опрашивается вся подсеть на порту `17580`. На втором этапе найденный кандидат проверяется по HTTP с SHA-1 авторизацией. Для защиты от пустых сканирований добавлена **проверка API Secret**: если ключ не введен, приложение выдает наглядное предупреждение. При успешном поиске IP автоматически вставляется, активируется фокус и **сразу сохраняется в SharedPreferences**, исключая потерю конфигурации.
   - **Быстрая проверка связи:** Кнопка «Проверить связь» мгновенно пингует xDrip+ с указанным IP и API Secret, выводя точный код ответа (200 OK, 401 Unauthorized или сетевая ошибка).
   - **Справка:** Подробная пошаговая инструкция на русском языке по клику на иконку знака вопроса в настройках.

10. **Проверка обновлений с GitHub прямо в приложении**:
    - Внедрена функция проверки актуальной версии из официального репозитория GitHub. Автопроверка запускается при открытии настроек, а также доступна ручная кнопка «Проверить».
    - При обнаружении нового релиза появляется кнопка быстрого скачивания APK-обновления.

11. **Быстрый выход из приложения и разделение кнопок**:
    - В правом верхнем углу главного экрана добавлена иконка быстрого выхода «крестик» (появляется при тапе и исчезает по таймауту вместе с остальными значками, имеет безопасный отступ от колокольчика во избежание ложных кликов).
    - В настройках внизу кнопка сохранения разделена на независимые кнопки «Отмена» и «Сохранить» для лучшего контроля изменений.

12. **Премиальная цветовая палитра (10 вариантов)**:
    - Внедрена изящная **горизонтальная прокручиваемая лента из 10 проверенных цветов** ночника (включая Янтарный, Красный для сохранения ночного зрения, Пурпурный, Зеленый, Синий, Желтый и Бирюзовый).
    - Абсолютная унификация: все элементы выбора цвета находятся строго в одну горизонтальную строку! Скролл-лента слева, а кнопка «Свой цвет» и индикатор превью расположены справа, прижатые к краю экрана.

13. **Автоинкремент версий и сборка**:
    - Интегрирована автоматическая инкрементация версии сборок. При каждой сборке приложения (gradle-задачи `assemble`, `install`, `bundle`, `generate`) скрипт Gradle автоматически считывает текущий номер сборки из файла `app/version.properties`, увеличивает `VERSION_CODE` и `VERSION_BUILD` на единицу и записывает их обратно.
