# Чек-лист выполнения задач DiaClock

- [ ] `1. Автоматический Snooze (откладывание тревоги)`
  - [ ] Реализовать `autoSnoozeRunnable` и его запуск на 15 минут в `startAlarmSound()`
  - [ ] Отмена `autoSnoozeRunnable` при `stopAlarmSound()`
  - [ ] Тщательная проверка, что при выключенном колокольчике тревоги заглушены и не могут сработать

- [ ] `2. Смещение интерфейса вверх и автоскрытие иконок`
  - [ ] Изменить `app:layout_constraintVertical_bias` для `@id/centralClickArea` на `0.38` в `activity_main.xml`
  - [ ] Реализовать перехват касаний в `dispatchTouchEvent(MotionEvent ev)` для сброса таймера бездействия
  - [ ] Реализовать плавное затухание (fade out) через 15 секунд бездействия для иконки настроек, батареи и колокольчика (если выключен)

- [ ] `3. Отображение IoB (Активный инсулин)`
  - [ ] Изменить `layoutGlucose` in `activity_main.xml` на `ConstraintLayout`
  - [ ] Добавить `@id/tvIoB` справа вверху от `@id/tvGlucose` зеленым цветом `#34C759` и размером `50sp`
  - [ ] Парсить поле `iob` в `fetchGlucoseData()` и выводить его на экран в формате `X.XX U` (или скрывать, если данных нет)

- [ ] `4. Pixel Shifting (Защита от выгорания OLED)`
  - [ ] Создать `pixelShiftHandler` и `Runnable`, запускаемый каждые 2 минуты
  - [ ] Смещать `@id/centralClickArea` по осям X и Y на случайную величину от -16 до +16 пикселей

- [ ] `5. Частое обновление данных`
  - [ ] Изменить задержку сетевого опроса с 60 секунд на 10 секунд в `startNetworkPolling()`

- [ ] `6. Отображение процента заряда батареи`
  - [ ] Создать векторные иконки `ic_battery.xml` и `ic_battery_charging.xml`
  - [ ] Разместить контейнер `@id/ivBatteryContainer` в правом нижнем углу `activity_main.xml`
  - [ ] Реализовать `BroadcastReceiver` для обновления уровня заряда и иконки в зависимости от подключения питания

- [ ] `7. Логика скрытия пиктограмм (Колокольчик)`
  - [ ] Доработать метод `fadeAttributesOut()`: скрывать колокольчик при бездействии только если `alarmEnabled == false`

- [ ] `8. Дополнительные настройки для слабоподготовленных пользователей`
  - [ ] Создать иконку справки `ic_help.xml` и добавить ее в `SettingsActivity` для открытия диалога со справкой
  - [ ] Добавить кнопку/иконку автопоиска IP в `SettingsActivity` рядом с полем IP, реализовать сканирование подсети
