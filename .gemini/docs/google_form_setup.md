# Инструкция по настройке Google Формы для телеметрии

Для того чтобы приложение могло отправлять статистику установок напрямую в ваши Google Таблицы без использования сторонних платных сервисов аналитики, вам нужно выполнить следующие шаги:

---

## Шаг 1. Создание формы
1. Перейдите в [Google Формы](https://forms.google.com).
2. Создайте новую **пустую форму** (назовите её, например, `DiaNight Installs`).
3. Добавьте три вопроса с типом ответа **«Текст (строка)»** / **«Short answer»**:
   *   **Market** (сюда будет записываться маркет: `Google Play`, `RuStore` или `APK / Side-load`)
   *   **Version** (сюда будет записываться версия приложения, например, `1.1.34`)
   *   **Device** (сюда будет записываться модель устройства, например, `Samsung SM-S901B`)
   
   *(Время установки Google Формы записывают автоматически в поле «Timestamp», создавать отдельное поле для даты не нужно).*

---

## Шаг 2. Получение ссылки для отправки ответов (formResponse)
1. В правом верхнем углу нажмите кнопку **«Просмотр»** (иконка глаза). Откроется публичная страница формы для заполнения.
2. Посмотрите на URL-адрес в строке браузера. Он будет выглядеть примерно так:
   `https://docs.google.com/forms/d/e/1FAIpQLSfXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX/viewform`
3. Скопируйте эту ссылку и замените в конце `/viewform` на **/formResponse**. Получится адрес для отправки данных:
   `https://docs.google.com/forms/d/e/1FAIpQLSfXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX/formResponse`
   *(Этот URL-адрес мы пропишем в коде приложения).*

---

## Шаг 3. Получение идентификаторов полей (entry.XXXXX)
Каждому текстовому полю в Google Форме соответствует свой уникальный внутренний ID (в формате `entry.123456789`). Нам нужно их узнать:

1. На странице просмотра формы (где вы видите поля для ввода ответов) нажмите клавишу **F12** (или нажмите правой кнопкой мыши на любое поле ввода и выберите **«Просмотреть код» / «Inspect»**).
2. Найдите в HTML-коде тег `<input>` для каждого поля:
   *   Например, для поля ввода **Market** найдите `<input type="text" ... name="entry.111111111" ...>`
   *   Скопируйте значение атрибута `name` (например, `entry.111111111`).
3. Повторите процедуру для полей **Version** (например, `entry.222222222`) и **Device** (например, `entry.333333333`).

---

## Шаг 4. Передача данных разработчику (мне)
Когда вы получите эти данные, пришлите их мне в таком виде:
*   **URL формы:** `https://docs.google.com/forms/d/e/.../formResponse`
*   **ID поля Market:** `entry.111111111`
*   **ID поля Version:** `entry.222222222`
*   **ID поля Device:** `entry.333333333`

Я встрою их в код. Пока вы настраиваете форму, я приступаю к реализации остальных задач!
