# План реализации: Настраиваемый Ночник Глюкозы и Часов (Glucose & Clock Nightstand)

Проект представляет собой специализированное Android-приложение (Java, API 23+) для использования в качестве прикроватных часов-ночника в ландшафтном режиме. Приложение отображает текущее время и уровень глюкозы в крови (получаемый из Nightscout-совместимого API) с автоматическим переключением, поддерживает кастомные цветовые градиенты, имеет встроенную систему умных будильников для дневного и ночного времени и гибкие настройки.

---

## Требуется обзор пользователем (User Review Required)

> [!IMPORTANT]
> **Важные архитектурные и технические решения:**
> 1. **Версия API и стек**: Проект создается на базе чистого Android SDK (Java) с минимальной поддержкой API 23 (Android 6.0) и целевой версией API 33 (Android 13). Используются библиотеки: `OkHttp` для сетевых запросов, `Gson` для парсинга данных, `Material Components` для современного темного дизайна экрана настроек.
> 2. **Приоритет экрана (Keep Screen On)**: В разметку `MainActivity` внедрен атрибут `android:keepScreenOn="true"`, чтобы экран не гас во время использования в качестве ночника.
> 3. **Локальный опрос сети**: Запросы к `http://[IP]:17580/sgv.json` выполняются каждые 60 секунд в фоновом потоке с помощью OkHttp с обработкой ошибок сети. При сбое отображается иконка предупреждения, а при восстановлении связи она исчезает.
> 4. **Интервалы будильников**: Используется сравнение текущего времени с настраиваемыми диапазонами (День/Ночь). Если глюкоза выходит за рамки текущего порога (высокий/низкий) и звук включен (желтый колокольчик), проигрывается стандартный сигнал тревоги.

## Открытые вопросы (Open Questions)

> [!NOTE]
> 1. **Формат JSON ответа**: Мы предполагаем стандартный формат Nightscout: JSON-массив объектов, где первый элемент содержит числовое поле `"sgv"` (например, `[{"sgv": 108, "direction": "Flat", "date": 1622500000000}]`), либо одиночный JSON-объект с полем `"sgv"`. Мы реализуем устойчивый парсинг обоих вариантов.
> 2. **Звук будильника**: Мы планируем использовать стандартный системный сигнал уведомления/будильника через `MediaPlayer`. Есть ли предпочтения по длительности сигнала? Мы сделаем так, чтобы сигнал звучал циклически с интервалом в несколько секунд при выходе за пределы, чтобы не разряжать батарею и не вызывать панику.

### 4. Исходный код Java

#### [NEW] [MainActivity.java](file:///h:/DiaClock/app/src/main/java/com/diaclock/nightstand/MainActivity.java)
Основная логика приложения:
- **Инициализация**: Чтение настроек из `SharedPreferences`. Применение выбранного градиента к тексту.
- **Интерфейс**:
  - `Handler` для периодического переключения между временем и глюкозой (интервал X секунд).
  - `Handler` / `Animator` для анимации двоеточия (альфа плавно меняется от 0.3 до 1.0 каждую секунду).
  - Обработка нажатия на центральный текст для циклического переключения между 5 предустановленными градиентами.
  - Нажатие на колокольчик переключает его состояние и сохраняет его.
  - Нажатие на шестеренку запускает `SettingsActivity`.
- **Сеть и опрос**:
  - Фоновый таймер (каждые 60 секунд) делает запрос к `http://[IP]:17580/sgv.json`.
  - Парсинг ответа. Если значение получено успешно — убираем иконку ошибки связи, пересчитываем в mmol/L (`sgv / 18.0`).
  - Если произошла сетевая ошибка — показываем предупреждающую иконку, сохраняем последнее известное значение (или выводим `---`).
- **Будильники**:
  - Метод проверки выхода глюкозы за пороги.
  - Определение текущего временного слота (День/Ночь) на основе системных часов устройства и настроенных диапазонов.
  - Если значение выходит за рамки текущего диапазона И колокольчик активен: запускается воспроизведение циклического звука предупреждения с помощью `MediaPlayer`.
  - Если значение вернулось в норму или колокольчик выключен: воспроизведение прекращается.

### Ручное тестирование и компиляция
1. **Сборка проекта**: Локальный запуск сборки Gradle (`./gradlew assembleDebug` или сборка в Android Studio) для проверки отсутствия ошибок компиляции.
2. **Проверка UI**:

   - Проверка черного фона, центрирования текста, анимации ":" двоеточия (плавное затухание раз в секунду).
   - Проверка циклического переключения градиентов при нажатии на текст (5 вариантов).
   - Проверка сохранения выбранного градиента после перезапуска приложения.
3. **Проверка логики сети и ошибок**:
   - Ввод корректного и некорректного IP в настройках.
   - Проверка отображения иконки предупреждения при недоступности сервера.
   - Эмуляция сервера sgv.json с помощью локального mock-сервера для подтверждения корректности парсинга и отображения mmol/L.
4. **Проверка будильников**:
   - Установка дневных и ночных порогов.
   - Моделирование значений глюкозы ниже Low и выше High для текущего времени (системного времени устройства).
   - Проверка воспроизведения звука при активном колокольчике и его прекращения при отключении колокольчика.
