# План реализации: Режим ночника, отслеживание установок и выбор языка

Этот документ описывает технические решения для добавления новых функций в приложение DiaNight: режима использования только в качестве ночника (без отображения сахара), отслеживания количества установок для разных маркетов и выбора языка интерфейса (русский/английский).

---

## Вопросы и выбор вариантов для пользователя

> [!IMPORTANT]
> **1. Отслеживание установок (Аналитика маркетов):**
> Для правильного подсчета количества установок из разных источников (Google Play, RuStore, прямая установка APK) есть несколько подходов:
> *   **Вариант А (Без кода):** Google Play Console и RuStore Console автоматически ведут статистику установок для пользователей, скачавших приложение из этих магазинов.
> *   **Вариант Б (Легковесный HTTP-пинг - Рекомендуемый):** Мы внедрим класс `TelemetryTracker.java`, который при первом запуске определяет источник установки с помощью метода `context.getPackageManager().getInstallerPackageName()` (например, `"com.android.vending"` для Google Play, `"ru.yoomoney.rustore"` для RuStore, `null` для APK) и отправляет асинхронный фоновый запрос на ваш URL-адрес (счетчик или веб-хук).
> *   **Вариант В (Интеграция Firebase/AppMetrica SDK):** Установка полноценных библиотек аналитики. Это значительно увеличивает размер приложения и требует создания аккаунтов/файлов конфигурации (`google-services.json`).
> *Мы предлагаем реализовать **Вариант Б** с заготовкой URL в коде, чтобы не утяжелять приложение сторонними SDK.*
>
> **2. Размещение настроек в интерфейсе:**
> *   Мы предлагаем добавить новую секцию (карточку CardView) в настройки под названием **«Интерфейс и Язык»**, куда поместим:
>     *   Выбор языка (выпадающий список Spinner: Автоматически, Русский, English).
>     *   Флажок «Режим ночника (скрыть сахара)» для отключения функций мониторинга глюкозы.

---

## Предлагаемые изменения

### 1. Режим ночника (отключение сахаров)
*   В `activity_settings.xml` добавим флажок `chkNightlightMode` («Режим ночника (скрыть сахара)»).
*   В `SettingsActivity.java` добавим сохранение значения чекбокса в `SharedPreferences` под ключом `"nightlight_mode"` (по умолчанию `false`).
*   В `MainActivity.java`:
    *   При запуске и возврате на экран (`onResume()`):
        *   Считываем параметр `"nightlight_mode"`.
        *   Если он активен:
            *   Останавливаем фоновый опрос сети (`networkRunnable`) и/или отключаем прием Broadcast-сообщений от xDrip+, чтобы экономить заряд аккумулятора.
            *   Останавливаем циклическое переключение экрана (`startToggleCycle()`), принудительно скрываем разметку сахара (`layoutGlucose`) и отображаем только время (`layoutTime`).
            *   Скрываем иконки будильника (`ivAlarmBell`) и предупреждения сети (`ivNetworkWarning`).
            *   Полностью отключаем срабатывание звуковой тревоги при проверках.

### 2. Выбор языка (локализация)
*   Создадим файл ресурсов `app/src/main/res/values-ru/strings.xml` и перенесем туда текущие русские строки.
*   Файл по умолчанию `app/src/main/res/values/strings.xml` переведем на английский язык, чтобы он служил языком по умолчанию (fallback) для англоязычных пользователей.
*   Добавим выпадающий список (Spinner) в настройки для переключения языков:
    *   **System Default (Автоматически)**
    *   **Русский**
    *   **English**
*   Для переключения локали будем использовать стандартный API библиотеки AppCompat: `AppCompatDelegate.setApplicationLocales(LocaleListCompat.forLanguageTags(langCode))`.
    *   Этот API сам сохраняет выбор во внутреннее хранилище AppCompat и применяет его на лету.
    *   В `AndroidManifest.xml` пропишем службу метаданных `AppLocalesMetadataHolderService` для поддержки автосохранения языка на старых версиях Android (ниже Android 13).

### 3. Отслеживание установок (аналитика)
*   Создадим класс `TelemetryTracker.java` в пакете `com.diaclock.nightstand`.
*   При первом запуске приложения (контролируется флагом `"first_launch_tracked"` в `SharedPreferences`):
    *   Проверяем имя установщика через `context.getPackageManager().getInstallerPackageName(packageName)`.
    *   Определяем маркет: `Google Play`, `RuStore`, `APK / Side-load`.
    *   Отправляем асинхронный HTTP GET запрос с помощью `OkHttpClient` на эндпоинт аналитики (в коде оставим константу `TELEMETRY_URL = ""`, которую вы сможете настроить).
    *   После попытки отправки сохраняем флаг `"first_launch_tracked" = true`, чтобы не отправлять запрос повторно при каждом запуске.

## План верификации

### Автоматические тесты
*   Запуск синтаксической сборки gradle для подтверждения отсутствия ошибок компиляции: `./gradlew assembleDebug`.

### Ручное тестирование на устройстве:
1.  **Тестирование режима ночника:**
    *   Включить в настройках «Режим ночника». Сохранить настройки.
    *   Экран должен показывать только время, переключение на сахара не должно происходить.
    *   Иконки колокольчика и знака предупреждения должны скрыться.
    *   Убедиться, что сетевые запросы прекратились (по логам) и тревога не срабатывает.
    *   Выключить режим ночника — мониторинг сахаров и иконки должны восстановиться.
2.  **Тестирование локализации (языка):**
    *   Переключить язык в настройках на English — интерфейс настроек и главного экрана должен мгновенно перевестись на английский язык.
    *   Переключить обратно на Русский.
    *   Переключить на "System Default" — язык должен совпадать с текущим языком системы устройства.
3.  **Тестирование трекера установок:**
    *   Запустить приложение на эмуляторе/устройстве в первый раз.
    *   В логах (Logcat) убедиться в выводе информации об успешном определении источника установки (например, `"Installer detected: null"` или `"Installer detected: com.android.packageinstaller"`).
    *   Проверить, что отправляется фоновый HTTP-запрос (при указанном URL).
