# Список улучшений (Выполнено)

Все запланированные задачи из этого списка были успешно реализованы.

## 1. Безопасность данных и контроль актуальности
* [x] **Контроль таймаута (макс. 15 минут):**
  * [x] Внедрен таймер контроля актуальности данных для режимов опроса сети (`network`) и локального вещания (`broadcast`).
  * [x] Если новые значения сахара отсутствуют дольше 15 минут, пользователь гарантированно оповещается визуально (показ предупреждения вместо устаревших данных).
* [x] **Автоматическое восстановление связи и сканирование сети:**
  * [x] Реализовано сканирование локальной подсети (порт `17580`) для автоматического обнаружения источников xDrip.
  * [x] Добавлена поддержка сканирования всей сети с выводом списка доступных источников и предложением выбора, если в сети находится несколько xDrip.

## 2. Поворот экрана на 180 градусов (Reverse Landscape)
* [x] В `AndroidManifest.xml` для `MainActivity` и `SettingsActivity` включена поддержка `sensorLandscape` (вместо фиксированного `landscape`).
* [x] Экран теперь корректно поворачивается на 180 градусов в зависимости от положения устройства, что удобно при зарядке кабелем с разных сторон.

## 3. Увеличение размера шрифтов на 5-10%
* [x] Переработаны формулы масштабирования в методах `adjustTextSizes()` и `adjustGlucoseAndIoBTextSizes()`.
* [x] Базовые размеры часов (`tvHours`, `tvColon`, `tvMinutes`), показателей глюкозы (`tvGlucose`) и активного инсулина (`tvIoB`) увеличены для оптимального заполнения свободного места на современных экранах.
